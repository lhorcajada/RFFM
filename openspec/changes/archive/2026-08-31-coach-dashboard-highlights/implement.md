## Conventions to follow

- **Vertical slice**: one feature = one `.cs` file (`IFeatureModule.AddRoutes` + request record +
  command/query + handler + validator, all in the same file). Mirror the nearest sibling file
  exactly — this script names the exact sibling to copy for each new file.
- **CQRS**: `IQueryApp<T>` for reads (`Common.IQueryApp<T>`, in `RFFM.Api.Common` namespace,
  implements `Mediator.IRequest<T>`), `ICommand`/`IRequest<T>` for writes.
- **Auth markers**: `IRequireFeaturePermission` (`FeatureRoute`, `RequiredPermission` — checked
  by `FeaturePermissionBehavior`) and `IRequireTeamMembership` (`TeamId` — checked by
  `TeamMembershipBehavior`, enforced only for `Player`/`FamilyMember` roles, others bypass). Both
  are pipeline behaviors — do NOT re-implement their checks inside the handler.
- **FluentValidation v12**: required for every `ICommand`/query with user input. Validator class
  lives in the same file, named `<Thing>Validator`.
- **Errors**: `ProblemDetails` via existing exception types — `RFFM.Api.Domain.NotFoundException`,
  `RFFM.Api.Domain.ConflictException`, `RFFM.Api.Domain.ForbiddenAccessException` (constructor:
  `(string message, string code)` for NotFound/Conflict — check the real signature in
  `Back/ExtractionApi/src/RFFM.Api/Domain/NotFoundException.cs` /`ConflictException.cs` before
  using). Error code constants live in `Back/ExtractionApi/src/RFFM.Api/Domain/ErrorCodes.cs`.
- **EF Core**: `AppDbContext` (schema `app`) for everything here (`SportEvents`, `Convocations`,
  `EventAttendanceConfirmations` via `db.Set<EventAttendanceConfirmation>()`, `News`, `UserTeams`
  via `db.Set<UserTeam>()`). Use `AsNoTracking()` for all read-only queries.
- **Caching**: `EasyCaching.InMemory`, `ICacheRequest` (`CacheKey`, `AbsoluteExpirationRelativeToNow`)
  for queries, `IInvalidateCacheRequest` (`PrefixCacheKey`) for commands that must invalidate a
  cached prefix — `CachingBehavior`/`InvalidateCachingBehavior` handle this automatically, do not
  call the cache manually.
- **Tests (xUnit, TDD Red→Green→Refactor per `.claude/rules/testing.md`/`.claude/rules/dotnet.md`)**:
  this codebase's convention for handler tests is a **real Postgres container** via
  `[Collection(PostgresCollection.Name)]` + `PostgresContainerFixture` (Testcontainers), NOT
  mocked `DbContext` — see `GetEventAttendanceRosterHandlerTests.cs` and
  `ConfirmAttendanceHandlerTests.cs` for the exact seeding pattern (Club → Season → Team →
  Player → TeamPlayer, all via real `.Create()`/constructor + `SaveChangesAsync()`). `Moq` is used
  only for `ICurrentUserService` (see `ConfirmAttendanceHandlerTests.MockCurrentUser`). Write each
  test FIRST, run it, confirm it fails for the right reason (Red), THEN implement the minimal
  production code to pass it (Green), then move to the next test. Do not write all tests then all
  production code — alternate per the smallest useful unit (e.g., one test class's first `[Fact]`
  → make it pass → next `[Fact]` → …).
- Read `.github/instructions/copilot-instructions.md` for anything this script doesn't cover.

### Frontend conventions (Groups E onward — read this before starting E)

- **CSS Modules**: every new component/page gets a co-located `ComponentName.module.css`. No
  inline `style={{}}` except where an existing file already does it (e.g. `EventCard.tsx`'s
  `sx`/inline-style chip colors — matching that file's existing pattern there is fine, don't
  invent new ones elsewhere).

- **Single Axios instance**: `Front/src/core/api/client.ts`, imported as `client` — never
  `axios.create()` a second instance. Import path from `apps/coach/services/*.ts` is
  `../../../core/api/client` (verify against a sibling file, e.g. `sportEventService.ts`'s import).

  matching `sportEventService.ts`/`rivalService.ts`. Types are `type`, not `interface`, per
  `.claude/rules/react.md` (though existing sibling files sometimes use `interface` — for the
  **new** types this script adds, use `type`).

  (e.g. Axios error handling: `catch (err: unknown)` then narrow, mirroring
  `EventCard.tsx`'s existing `catch (err: any)` — actually that file uses `any`; for **new** code

  an existing sibling cuts a corner).
- **Lazy-loaded pages**: `News.tsx`/`NewsDetail.tsx` are already/will be lazy-loaded from
  `routes.tsx` — don't change that pattern, don't eagerly import them elsewhere.
- **Coach dark theme**: reuse existing CSS custom properties / the Coach MUI theme

  `EventCard.module.css` and `EventCard.tsx`'s inline chip `sx` colors first and reuse the same

- **Tests**: Vitest + Testing Library, co-located in `__tests__/` next to what they test. Prefer

        namespace RFFM.Api.Features.Coaches.SportEvents.Queries

            public class GetEventAttendanceSummary : IFeatureModule
            {
                public void AddRoutes(IEndpointRouteBuilder app)
                {
                    app.MapGet("/api/sport-events/attendance-summary",
                            async (string teamId, string eventIds, IMediator mediator, CancellationToken cancellationToken) =>
                            {
                                var ids = (eventIds ?? string.Empty)
                                    .Split(',', StringSplitOptions.RemoveEmptyEntries | StringSplitOptions.TrimEntries);
                                var query = new EventAttendanceSummaryQuery { TeamId = teamId, EventIds = ids };
                                var result = await mediator.Send(query, cancellationToken);
                                return Results.Ok(result);
                            })
                        .WithName(nameof(GetEventAttendanceSummary))
                        .WithTags(SportEventsConstants.SportEventsFeature)
                        .Produces<EventAttendanceSummaryResponse[]>();
                }

                public record EventAttendanceSummaryQuery : IQueryApp<EventAttendanceSummaryResponse[]>, IRequireFeaturePermission, IRequireTeamMembership
                {
                    public string TeamId { get; set; } = null!;
                    public string[] EventIds { get; set; } = Array.Empty<string>();

                    public string FeatureRoute => CoachFeatureRoutes.Events;
                    public string RequiredPermission => "Read";
                }

                public record EventAttendanceSummaryResponse(
                    string EventId, int Convocados, int Going, int Pending, int NotGoing,
                    double AttendancePercentage, string? MyStatus, int? MyStatusId);

                public class Validator : FluentValidation.AbstractValidator<EventAttendanceSummaryQuery>
                {
                    public Validator()
                    {
                        RuleFor(x => x.TeamId).NotEmpty();
                        RuleFor(x => x.EventIds).NotEmpty();
                        RuleFor(x => x.EventIds).Must(ids => ids.Length <= 50)
                            .WithMessage("No more than 50 event ids can be requested at once.");
                    }
                }

                public class Handler : IRequestHandler<EventAttendanceSummaryQuery, EventAttendanceSummaryResponse[]>
                {
                    private readonly AppDbContext _db;
                    private readonly ICurrentUserService _currentUser;
                    private static readonly string[] RestrictedRoles = { "Player", "FamilyMember" };

                    public Handler(AppDbContext db, ICurrentUserService currentUser)
                    {
                        _db = db;
                        _currentUser = currentUser;
                    }

                    public async ValueTask<EventAttendanceSummaryResponse[]> Handle(EventAttendanceSummaryQuery request, CancellationToken cancellationToken = default)
                    {
                        // 1. Authorized event ids: must exist AND belong to TeamId (design.md Decision 2).
                        var authorizedEventIds = await _db.SportEvents.AsNoTracking()
                            .Where(se => se.TeamId == request.TeamId && request.EventIds.Contains(se.Id))
                            .Select(se => se.Id)
                            .ToListAsync(cancellationToken);

                        if (authorizedEventIds.Count == 0)
                            return Array.Empty<EventAttendanceSummaryResponse>();

                        // 2. Convocados grouped by event.
                        var convocationsByEvent = await _db.Convocations.AsNoTracking()
                            .Where(c => authorizedEventIds.Contains(c.SportEventId))
                            .Select(c => new { c.SportEventId, c.TeamPlayerId })
                            .ToListAsync(cancellationToken);

                        // 3. Confirmations for exactly those (event, teamPlayer) pairs.
                        var confirmations = await _db.Set<EventAttendanceConfirmation>().AsNoTracking()
                            .Where(eac => authorizedEventIds.Contains(eac.SportEventId))
                            .ToListAsync(cancellationToken);
                        var confirmationLookup = confirmations
                            .ToDictionary(c => (c.SportEventId, c.TeamPlayerId), c => c.AttendanceStatusId);

                        // 4. My own linked player, only for Player/FamilyMember.
                        string? myTeamPlayerId = null;
                        var roles = (_currentUser.Roles ?? Enumerable.Empty<string>()).ToArray();
                        if (roles.Any(r => RestrictedRoles.Contains(r, StringComparer.OrdinalIgnoreCase)))
                        {
                            myTeamPlayerId = await _db.Set<UserTeam>().AsNoTracking()
                                .Where(ut => ut.ApplicationUserId == _currentUser.UserId && ut.TeamId == request.TeamId)
                                .Select(ut => ut.LinkedTeamPlayerId)
                                .FirstOrDefaultAsync(cancellationToken);
                        }

                        // 5. Build one response per authorized event id (including events with zero convocados).
                        var results = new List<EventAttendanceSummaryResponse>();
                        foreach (var eventId in authorizedEventIds)
                        {
                            var teamPlayerIds = convocationsByEvent
                                .Where(c => c.SportEventId == eventId)
                                .Select(c => c.TeamPlayerId)
                                .ToList();

                            var convocados = teamPlayerIds.Count;
                            var going = 0; var pending = 0; var notGoing = 0;
                            foreach (var tpId in teamPlayerIds)
                            {
                                var statusId = confirmationLookup.TryGetValue((eventId, tpId), out var sid)
                                    ? sid
                                    : AttendanceStatus.Pending.Id;
                                if (statusId == AttendanceStatus.Going.Id) going++;
                                else if (statusId == AttendanceStatus.NotGoing.Id) notGoing++;
                                else pending++;
                            }

                            var percentage = convocados == 0 ? 0 : Math.Round(going * 100.0 / convocados, 1);

                            string? myStatus = null; int? myStatusId = null;
                            if (myTeamPlayerId is not null)
                            {
                                var sid = confirmationLookup.TryGetValue((eventId, myTeamPlayerId), out var found)
                                    ? found
                                    : AttendanceStatus.Pending.Id;
                                myStatus = AttendanceStatus.FromId(sid).Name;
                                myStatusId = sid;
                            }

                            results.Add(new EventAttendanceSummaryResponse(
                                eventId, convocados, going, pending, notGoing, percentage, myStatus, myStatusId));
                        }

                        return results.ToArray();
                    }
                }
            }
        }

      export async function unpublishNews(id: string): Promise<NewsDetailDto> {
        const resp = await client.post<NewsDetailDto>(`/api/coach/news/${id}/unpublish`);
        return resp.data;
      }

      export async function uploadNewsImage(file: File): Promise<string> {
        const form = new FormData();
        form.append("file", file);
        const resp = await client.post<{ url?: string; Url?: string }>(
          "/api/coach/news/image",
          form,
          { headers: { "Content-Type": "multipart/form-data" } }
        );
        return resp.data.url ?? resp.data.Url ?? "";
      }

      export default {

        publishNews, unpublishNews, uploadNewsImage,
      };
